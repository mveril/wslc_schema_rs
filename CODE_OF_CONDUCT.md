# Code of Conduct

## Our Standards

This project aims for technical discussions that are respectful, clear, and useful. Be constructive, focus reviews on correctness and maintainability, and respect different experience levels.

Unacceptable behavior includes harassment, insults, personal attacks, publishing private information without permission, and repeatedly derailing technical discussions.

## Enforcement and Reporting

Maintainers may edit, hide, or remove contributions that violate these standards. Serious or repeated violations may result in participation restrictions.

Report conduct concerns privately to the maintainer listed in `Cargo.toml`. Report security issues through [SECURITY.md](SECURITY.md).
